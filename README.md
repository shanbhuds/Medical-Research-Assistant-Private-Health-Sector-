# Medical-Research-Assistant-Private-Health-Sector-
Medical Research Assistant (Private Health Sector)
A secure web application built with Flask, featuring an advanced medical chatbot powered by LLMs and RAG technology. This locally running solution combines Langchain's agents with FAISS vector storage and SQLite to deliver personalized healthcare assistance without requiring API keys.
The assistant helps patients access medical information through RAG-enhanced knowledge retrieval, manages appointments with suitable doctors based on symptoms, and even handles emergency reporting with triage color coding for healthcare professionals.
Note: This application is for demonstration purposes only and does not provide actual medical advice.RetryClaude can make mistakes. Please double-check responses.
